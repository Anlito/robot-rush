Robot Rush · Mise en place en salle

Mode local : le jeu tourne sur le PC du professeur, les élèves s'y connectent par le réseau du collège. Rien à installer sur leurs postes.

À faire une fois, avant le premier cours (idéalement quelques jours avant, avec un poste élève à côté) : étapes 1 à 3 ci-dessous. Si le poste élève n'arrive pas à se connecter, il reste le temps de voir le référent numérique.

0Copier le dossier

  • Copier le dossier RobotRush en entier sur le PC prof (par exemple dans Documents). Le lancer depuis la clé USB marche aussi, plus lentement.
  • Le dossier contient tout : le jeu, ses composants et Node.js (version portable, rien à installer, pas besoin de droits d'administrateur).

1Lancer le jeu

  • Brancher le PC au réseau du collège (le même que les postes élèves).
  • Double-cliquer sur Lancer Robot Rush.vbs (ou sur demarrer.bat). Une fenêtre noire s'ouvre : la laisser ouverte tout le cours. Si l'invite de commandes est désactivée par l'administrateur, demarrer.bat s'ouvre et se ferme aussitôt : utiliser Lancer Robot Rush.vbs.
  • Pare-feu Windows : s'il pose la question, cocher Réseaux privés (et « domaine » s'il est proposé), puis Autoriser l'accès. Sans droits d'administrateur, Windows peut refuser : voir le plan B en bas.
  • Noter l'adresse affichée dans la fenêtre noire, par exemple 192.168.1.25:3000.

2Espace professeur

  • Le navigateur s'ouvre sur l'espace professeur. Mot de passe : robot.
  • Changer le mot de passe (une fois) : fermer la fenêtre noire, ouvrir config-serveur.json avec le Bloc-notes, remplacer "robot" par le vôtre (garder les guillemets), enregistrer, relancer demarrer.bat.

3Tester depuis un poste élève

  • Sur un poste élève, ouvrir le navigateur et taper l'adresse suivie de /test, par exemple 192.168.1.25:3000/test.
  • La page doit afficher « Connexion réussie ». Sinon : voir « Si ça ne marche pas ».

4Le jour du cours

  1. Lancer demarrer.bat 5 minutes avant.
  2. Espace professeur : choisir le parcours, le nombre d'équipes.
  3. Lien « Ouvrir /course » en haut → sur le vidéoprojecteur, plein écran (F11).
  4. Les élèves tapent l'adresse affichée au tableau (ou scannent le QR code), puis le code de leur équipe et un pseudo.
  5. ▶ Démarrer la course.
  6. À la fin : fermer la fenêtre noire.

!Bon à savoir

  • Un élève qui actualise ou ferme l'onglet retrouve son équipe en rouvrant l'adresse.
  • Les questions créées dans l'espace professeur sont gardées dans le dossier data.
  • Aucun pseudo d'élève n'est enregistré après la partie.
  • Aucune connexion à internet n'est nécessaire.

Ce qu'on voitQue faire
La fenêtre noire s'ouvre et se ferme aussitôtL'invite de commandes est désactivée : lancer Lancer Robot Rush.vbs. Si lui aussi est bloqué : raccourci manuel, voir MODE-LOCAL.md.
Message « Windows a refusé de lancer Node.js » ou « bloqué par l'administrateur »Le PC interdit les programmes copiés : demander au référent numérique d'autoriser RobotRush\node\node.exe, ou utiliser la version en ligne.
« Le port 3000 est déjà utilisé »Rien à faire : le jeu prend le port suivant. Donner aux élèves la nouvelle adresse affichée.
Le poste élève n'ouvre pas la page (délai dépassé)1) Même réseau que le PC prof ? (pas de Wi-Fi invité) 2) Essayer l'« autre adresse » affichée dans la fenêtre noire. 3) Pare-feu : voir plan B.
« Aucun réseau détecté »Brancher le câble réseau ou se connecter au Wi-Fi du collège, attendre quelques secondes.
La page /test s'ouvre mais « temps réel » échoueEssayer un autre navigateur sur le poste élève ; sinon un filtrage bloque les WebSockets : voir le référent numérique.
Plan B pare-feu (si le poste élève n'arrive pas à se connecter et que Windows n'a rien demandé, ou a refusé faute de droits) : demander au référent numérique d'autoriser sur le PC prof les connexions entrantes vers node.exe (dans le dossier RobotRush\node), ou le port TCP 3000, sur le réseau du collège. Autre solution : un point d'accès Wi-Fi dédié à la classe. Guide détaillé : MODE-LOCAL.md dans le dossier.
